# 📘 Avaliação - Média do Aluno

Projeto desenvolvido para a disciplina de **Programação Web Full Stack** da UTFPR 

## 📋 Descrição

Aplicação web simples que recebe o nome e 4 notas de um aluno, calcula a média em tempo real e exibe o status:
- ✅ **APROVADO** - Média maior que 6
- 📝 **EXAME** - Média entre 2 e 5,9
- ❌ **REPROVADO** - Média menor que 2

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura da página
- **CSS3** - Estilização e layout
- **JavaScript** - Lógica de cálculo e interatividade

## 📁 Estrutura do Projeto

├── index.html # Página principal (formulário)
├── resultado.html # Página de resultado
└── README.md # Documentação do projeto

## ✨ Funcionalidades

- ✅ Campo para digitar o nome do aluno
- ✅ 4 campos para digitar as notas (0 a 10)
- ✅ Cálculo automático da média ao digitar as notas
- ✅ Exibição do status em tempo real (APROVADO/EXAME/REPROVADO)
- ✅ Validação: só permite enviar se todas as notas estiverem preenchidas
- ✅ Botão "Registrar resultado" redireciona para página com o resultado final

## 🚀 Como Executar

- Digite o nome do aluno
- Preencha as 4 notas (valores entre 0 e 10)
- A média e o status atualizam automaticamente
- Clique em "Registrar resultado" para ver o resumo em uma nova página
